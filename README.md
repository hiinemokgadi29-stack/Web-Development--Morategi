## Project Overview

The Kwelano Bohloko Old Age and Disability Centre Website is a community-focused website designed to provide information about the organisation, its services, community activities and ways for people to make enquiries.

The website is intended to provide a simple, accessible and informative online presence for an organisation that supports older persons and people with disabilities.

The website allows visitors to learn more about Kwelano Bohloko, view the services provided, submit an enquiry and find the organisation's contact and location information.

The project is developed using HTML as required for the website project.

---

## Website Goals and Objectives

### Goals

The main goal of the website is to create a clear and welcoming online presence for Kwelano Bohloko Old Age and Disability Centre.

The website aims to:

- Provide information about the organisation.
- Explain the services and community support offered.
- Make it easy for visitors to contact the organisation.
- Provide an online enquiry form.
- Provide the organisation's location.
- Encourage community involvement.
- Provide information for potential volunteers and community partners.
- Create a professional online presence for the organisation.

### Objectives

The website objectives are to:

1. Create a simple and easy-to-navigate website.
2. Provide clear information about Kwelano Bohloko.
3. Present the organisation's mission, vision and values.
4. Explain the services offered to the community.
5. Allow visitors to submit enquiries.
6. Provide telephone and email contact information.
7. Display the organisation's location using a map.
8. Make the website understandable and accessible to different users.
9. Maintain consistent navigation across all pages.
10. Provide references for information and development resources.

## Key Features and Functionality

The website contains the following main features:

### Home Page

The home page introduces Kwelano Bohloko Old Age and Disability Centre.

It includes:

- Welcome message.
- Introduction to the organisation.
- Community focus.
- Organisation values.
- Services overview.
- Community involvement information.
- Contact information.
- Navigation to the other website pages.

### About Us Page

The About Us page provides information about the organisation.

It includes:

- Who We Are.
- Our Story.
- Mission.
- Vision.
- Organisational values.
- Who the organisation serves.
- Community involvement.
- Organisation information.

### Services Page

The Services page explains the different areas of community support.

It includes:

- Support for older persons.
- Disability support.
- Community activities.
- Volunteer opportunities.
- Community partnerships.
- Service principles.
- Information about how visitors can make enquiries.

### Enquiry Page

The Enquiry page allows visitors to submit an enquiry.

The form includes fields for:

- Full name.
- Email address.
- Telephone number.
- Organisation or company.
- Type of enquiry.
- Preferred contact method.
- Enquiry message.
- Volunteer interest.
- Permission to be contacted.

### Contact Page

The Contact page provides ways to communicate with the organisation.

It includes:

- Telephone number.
- Alternative telephone number.
- Email address.
- Physical location.
- Map.
- Quick contact options.
- Link to the enquiry form.

### References Page

The References page documents the resources used during the development of the website.
